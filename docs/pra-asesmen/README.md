# Dokumen pra-asesmen untuk klien

Berkas untuk dikirim kepada klien sebelum asesmen dimulai. Versi pertama disiapkan untuk PT Adhi Karya (Persero) Tbk. pada 21 November 2026.

| Berkas | Isi |
|---|---|
| `Dokumen-Pra-Asesmen-NSCAS-Adhi-Karya.docx` | Pendahuluan, alur enam tahap, daftar periksa 12 butir, Formulir A sampai G (profil dan lingkup, penanggung jawab, persetujuan lokasi data dan perjanjian pemrosesan data, teks persetujuan responden, komitmen pimpinan, rencana validasi, kesiapan teknis), kerahasiaan, lembar penerimaan, dan tiga lampiran (contoh bukti per karakteristik, dokumen kunjungan proyek, rujukan) |
| `Lembar-Data-Pra-Asesmen-NSCAS-Adhi-Karya.xlsx` | Lembar isian: Unit, Strata dan Jabatan, Tim dan Akun, Penilaian Mandiri, Kunjungan Proyek, Narasumber, Bukti Dokumen |

Isinya diturunkan dari syarat sistem: syarat transisi tahap 1 dan 2 (`docs/01` bagian 3), matriks peran (`docs/04` bagian 2), syarat lokasi data dan teks persetujuan (`docs/04` bagian 1.1 dan 8), kalkulator sampel (`docs/03` bagian 7), contoh bukti dari `seed/instrumen-karakteristik-v1.json`, dan butir dokumen kunjungan dari `seed/panduan-validasi-v2.json`. Daftar responden sengaja tidak diminta dalam berkas ini; administrator klien mengunggahnya langsung ke NSCAS.

Bila syarat sistem berubah (misalnya instrumen versi 2), berkas ini perlu diperbarui.
